# morse-code-encoder-and-decoder
This project encodes English text into Morse code and decodes Morse code back into English. I built it to develop my Python skills while exploring how information can be encoded, transmitted, and decoded in communication systems.

Technologies: Python

What I learned: I learned how dictionaries, loops, and string processing can be used to map characters between different forms of encoded information.

Next step: Adding audio output to represent Morse code using short and long sound signals.
